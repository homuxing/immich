# 移动端

> 所属功能：子账户

## 页面

账户菜单提供：

- 主账户。
- 当前主账户的全部子账户。
- 当前账户选中状态。
- 创建、改名和删除子账户。

子账户不能出现在登录页。用户必须先登录主账户，再切换子账户。

## 切换流程

1. 停止当前账户的后台上传和同步任务。
2. 等待正在写入的本地数据结束。
3. 调用切换账户接口。
4. 重新读取 `/users/me` 和偏好设置。
5. 重新加载时间线、相册、文件夹、收藏、地图、探索、人物和搜索。
6. 使用新账户 ID 继续本地同步。
7. 重新建立实时连接。

切换失败时保持原账户和原任务状态。

## 本地数据

- 本地数据库按用户 ID 分开保存数据。
- 所有照片、相册和时间线查询必须带用户 ID。
- 切换时不删除其他账户的本地数据。
- 当前账户 ID 只在切换成功后更新。
- App 重启后以服务端会话和 `/users/me` 为准。

## 上传与后台任务

- 上传记录必须使用发起上传时的用户 ID。
- 切换前停止旧账户上传，避免照片写入错误账户。
- 后台备份、缩略图生成和同步任务必须使用当前账户 ID。
- Widget 和系统快捷入口显示当前账户名称。

## 页面权限

子账户模式隐藏：

- 修改密码。
- OAuth。
- Passkey。
- API Key。
- 子账户管理。
- 相册共享。
- Partner。
- 人物共享。
- 分享链接。

管理员入口按登录主账户权限显示。

子账户不能调用设备会话、账号资料、API Key、Passkey、OAuth、PIN 和子账户管理接口。移动端隐藏入口不能代替服务端限制。

## 验收

- 子账户不能从移动端登录页登录。
- 主账户可以创建、改名、删除和切换子账户。
- 切换后所有数据页面只显示子账户内容。
- 切换后上传照片属于子账户。
- 后台任务不会写入其他账户。
- App 重启后恢复正确账户。
- 切换后看不到旧账户数据。

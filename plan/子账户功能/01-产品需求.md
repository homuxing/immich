# 产品需求

> 所属功能：子账户

## 定位

子账户用于隔离同一主账户下的数据，不是独立账号。

这种隔离用于整理照片和避免时间线混在一起，不是加密隔离。登录主账户、服务器管理员以及拥有数据库或文件系统权限的人仍然可以访问这些数据。

典型用途：

- 主账户保存生活照片。
- 子账户保存插画、表情包、素材和其他不希望进入主时间线的内容。

## 子账户独立的内容

- 时间线。
- 文件夹视图和物理存储目录。
- 相册。
- 收藏、归档和回收站。
- 地图和探索。
- 搜索。
- 人物和标签。
- 回忆。
- 与照片展示相关的偏好。

## 子账户不包含的内容

- 邮箱和密码。
- OAuth、Passkey 和 API Key。
- 独立登录会话。
- 独立存储配额。
- 相册共享、Partner、人物共享和分享链接。
- 独立管理员权限。
- 独立账号管理功能。

子账户的组织结构和账号管理只由所属主账户负责。

每个主账户可创建的子账户数量受服务器配置上限限制，创建接口执行频率限制。

## 名称规则

- 名称不能为空，前后空格会被去除。
- 同一主账户下名称不能重复，比较时不区分大小写。
- 不同主账户可以使用相同名称。
- 名称只用于识别和切换数据空间，不作为登录名。

## 创建和管理

主账户在“用户设置 > 子账户”中：

- 查看自己的子账户。
- 创建子账户。
- 修改子账户名称。
- 删除子账户。
- 切换到子账户。

子账户创建后不会自动切换。

## 切换

1. 主账户打开账户菜单。
2. 选择子账户。
3. 服务端确认该子账户属于当前主账户。
4. 当前登录会话切换数据空间。
5. 客户端清理原账户页面数据。
6. 客户端加载子账户内容并进入照片首页。

切换只影响当前设备上的当前登录会话。

## 权限

- 主账户是普通用户时，子账户也只能使用普通用户功能。
- 主账户是管理员时，在子账户中仍可使用主账户的管理员权限。
- 子账户本身永远不是管理员。
- 子账户不增加或减少主账户的系统权限。

## 存储配额

子账户没有独立配额。子账户中的文件全部计入主账户存储用量，受主账户配额限制。

## 删除

删除子账户必须：

1. 让正在使用该子账户的会话返回主账户或失效。
2. 删除子账户数据库记录和关联数据。
3. 删除独立上传、缩略图、视频、头像和资料库目录。
4. 从子账户列表移除。

## 验收标准

- 子账户不能独立登录。
- 子账户名称在同一主账户下不能重复。
- 主账户未切换时看不到子账户照片。
- 子账户之间看不到彼此的数据。
- 主账户和子账户的收藏、地图、探索、文件夹和相册互相隔离。
- 子账户文件计入主账户配额。
- 管理员主账户切换子账户后仍保留系统管理权限。
- 删除子账户后数据库记录和物理文件都被清理。

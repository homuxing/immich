# 安全审查

> 所属功能：子账户  
> 审查结论：数据隔离方向合理，但必须按以下规则实现，不能只过滤用户列表或隐藏页面。

## 高风险问题

### 1. 子账户可绕过登录限制

现有通用接口会使用 `auth.user.id` 创建账号凭据或会话。子账户上下文因此可能：

- 修改邮箱和密码。
- 创建设备会话。
- 创建 API Key 或 Passkey。
- 绑定 OAuth。

修正：增加统一的“仅主账户可用”接口标记，在认证守卫中拒绝 `activeUserId != null`。设备会话、账号资料、凭据、License、Onboarding 和子账户管理全部受此限制。

### 2. 管理员权限和数据账户混用

如果直接在子账户对象上覆盖主账户的 `isAdmin`，管理员接口会出现“权限是主账户、ID 是子账户”的混合状态。现有自我删除保护会把子账户 ID 和主账户 ID 比较，可能允许管理员删除自己的主账户。

修正：

- `auth.user` 只表示当前数据账户。
- `auth.loginUser` 只表示登录主账户。
- 数据访问使用 `auth.user.id`。
- 管理员权限和自我操作保护使用 `auth.loginUser`。

### 3. 配额可以被绕过

子账户没有独立配额。如果继续使用 `auth.user.quotaSizeInBytes` 判断，空值会被视为不限量。现有新增和删除文件事件也只更新实际照片所有者。

修正：

- 上传时使用登录主账户的配额和主账户聚合用量。
- 新增和删除文件时，在同一事务中更新子账户用量和主账户总用量。
- 后台任务重新计算聚合用量。

### 4. 删除主账户可能留下无主文件

数据库资源会随用户记录级联删除，但物理文件不会。如果 `parentUserId` 也使用级联删除，主账户删除可能先删除子账户记录，导致后台任务无法再找到对应目录。

修正：

- `parentUserId` 使用 `ON DELETE RESTRICT`。
- 先停止登录并清理全部子账户文件和记录。
- 子账户全部删除后，再删除主账户。

## 中风险问题

### 5. 隐藏用户仍可能被直接引用

子账户不出现在搜索列表，但已知 ID 仍可能用于用户详情、头像、相册添加用户、Partner、人物共享或管理员用户接口。

修正：所有接收用户 ID 的普通接口都检查目标记录，`parentUserId != null` 时拒绝。管理员接口也不能直接修改或删除子账户。

### 6. 旧实时连接会泄漏事件

实时连接建立时加入当前账户 ID 对应的房间。切换账户后，旧连接不会自动退出。

修正：账户切换后由服务端按登录会话 ID 主动断开旧连接，客户端再重新连接。

### 7. 空邮箱破坏现有返回结构

现有用户响应要求邮箱为有效字符串，头像颜色也直接根据邮箱计算。子账户邮箱为空会导致类型、生成代码和页面显示出错。

修正：

- 用户响应邮箱允许为 `null`。
- 头像颜色使用名称或固定默认颜色。
- 重新生成 Web 和移动端接口代码。

### 8. 会话和删除状态需要再次校验

子账户软删除后，外键仍然存在。旧会话可能在软删除和强制删除之间继续访问。

修正：

- 每次请求同时检查登录主账户和活动子账户的删除、停用状态。
- 删除子账户时立即清空相关 `activeUserId`。
- 归属关系失效时拒绝请求。

### 9. 统计和后台任务会误算子账户

现有用户数量、用户统计、回忆任务、存储模板和清理任务都会遍历用户表。简单复用这些查询会让子账户被当成普通用户。

修正：

- 用户数量和普通用户统计只计算主账户。
- 回忆、存储模板、文件清理等数据任务明确包含子账户。
- 管理页面的用户列表不展示子账户。

### 10. 人脸分组可以绕过共享限制

现有的人脸分组接口可以在不同用户之间合并人物识别结果。即使关闭相册共享和 Partner，子账户仍可能通过加入其他人脸分组与其他用户共享人物数据。

修正：

- 子账户不能创建加入其他人脸分组的请求。
- 人脸分组用户列表不返回子账户。
- 子账户不能作为其他用户加入人脸分组的目标。

### 11. 多标签页和并发任务

同一浏览器标签页共用登录 Cookie。一个标签页切换账户后，其他标签页仍可能保留旧页面数据。上传和后台同步也可能在切换过程中继续写入旧账户。

修正：

- 切换后通过浏览器广播通道刷新全部标签页。
- 上传过程中禁止切换。
- 移动端切换前停止上传、备份和同步任务。

### 12. 子账户数量没有上限

每个已登录主账户都能创建记录、人脸分组和存储目录。如果没有上限，可能造成数据库和文件系统资源滥用。

修正：

- 每个主账户设置服务器配置的子账户数量上限。
- 创建接口增加频率限制。

### 13. 软删除会长期占用名称

如果唯一索引包含已删除记录，子账户删除后仍无法复用名称。

修正：名称唯一索引只覆盖未删除子账户。

## 安全边界

子账户只提供逻辑数据隔离，不提供对这些人的保密：

- 登录主账户。
- 服务器管理员。
- 拥有数据库、对象存储或媒体目录权限的人。

如果需要防止主账户或服务器管理员查看，必须增加独立加密和密钥管理，不属于当前方案。

## 上线前必须通过的测试

- 子账户不能创建密码、OAuth、Passkey、API Key 或设备会话。
- 子账户不能修改主账户资料或凭据。
- 管理员在子账户中不能误删主账户。
- 直接提交子账户 ID 的用户、相册、Partner 和管理员接口全部拒绝。
- 主账户达到配额后，所有子账户都不能继续上传。
- 切换后服务端断开旧实时连接。
- 主账户不能在子账户文件清理完成前被删除。
- 子账户软删除后旧会话立即失效或返回主账户。

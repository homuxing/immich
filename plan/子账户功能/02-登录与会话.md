# 登录与会话

> 所属功能：子账户

## 用户记录

子账户是隐藏的 `user` 记录，增加：

```text
parentUserId uuid null
```

- 空值表示主账户。
- 非空表示该主账户下的子账户。
- 子账户不能再拥有子账户。
- 子账户名称使用现有 `user.name` 字段。
- 子账户的 `email`、`password`、`oauthId` 和 `pinCode` 都为空。
- 子账户的 `isAdmin` 固定为 `false`。

`user.email` 改为可空。主账户仍然必须有邮箱。

## 名称规则

子账户名称：

- 去除前后空格后不能为空。
- 在同一 `parentUserId` 下不能重复。
- 去重比较不区分大小写。
- 不同主账户之间互不影响。

通过数据库唯一索引和服务端校验共同保证。

## 登录会话

`session.userId` 保持为真正登录的主账户 ID。

`session.activeUserId` 表示当前使用的子账户：

- 空值：主账户数据。
- 非空：对应子账户数据。

`AuthSession` 增加：

```ts
type AuthSession = {
  id: string;
  loginUserId: string;
  activeUserId: string | null;
  hasElevatedPermission: boolean;
};
```

`AuthDto` 必须分开保存登录账户和数据账户：

```ts
type AuthDto = {
  user: AuthUser;       // 当前照片数据所属账户，可能是子账户
  loginUser: AuthUser;  // 真正登录的主账户
  session?: AuthSession;
};
```

不能把登录主账户的 `isAdmin` 覆盖到子账户的 `user` 对象上。管理员权限只读取 `auth.loginUser`，照片数据只读取 `auth.user`。

## 登录限制

- 密码登录只允许主账户。
- 子账户没有邮箱和密码，不能登录。
- 子账户不能绑定 OAuth、创建 Passkey 或创建 API Key。
- 新的登录会话只能记录主账户。

登录接口必须显式检查 `parentUserId`，不能只依赖密码为空。

## 当前账户解析

每次使用登录会话请求时：

1. 读取 `session.userId` 对应的主账户。
2. 如果 `activeUserId` 为空，当前数据账户是主账户。
3. 如果 `activeUserId` 非空，读取对应子账户。
4. 确认子账户的 `parentUserId` 等于登录主账户。
5. `auth.user` 使用当前数据账户。
6. `auth.loginUser` 使用登录主账户。
7. `auth.session` 保存登录主账户和当前子账户。

归属不一致、账户已删除或字段无效时拒绝请求。

## 切换

- 只能由登录会话切换。
- API Key 和分享链接不能切换。
- 只能切换到当前登录主账户直属的子账户。
- 切换时清除锁定照片的临时解锁状态。
- 切回主账户时同样清除临时解锁状态。
- 切换后旧实时连接必须失效，客户端重新连接。

## 账号限制

子账户不能：

- 修改密码或 PIN。
- 绑定 OAuth。
- 创建 Passkey 或 API Key。
- 创建分享链接。
- 参与相册共享或 Partner。
- 创建、修改或删除子账户。
- 修改管理员权限。

这些请求在子账户下返回 `403 Forbidden`。

以下通用接口必须在服务端统一拒绝，不能只在 UI 隐藏：

- `/users/me` 的资料、邮箱和密码修改。
- 头像上传和删除。
- `/sessions` 全部设备会话管理，包括创建设备会话。
- `/api-keys` 全部接口。
- `/passkeys` 全部管理接口。
- OAuth 绑定和解绑。
- PIN 设置、修改和重置。
- License 和 Onboarding 修改。
- 子账户创建、改名和删除。

登录会话中的 PIN 解锁属于登录主账户，必须读取 `auth.loginUser.id`，使主账户 PIN 可以解锁当前子账户中的锁定照片。

`GET /auth/status` 中的密码、PIN 和临时解锁状态也读取登录主账户，不能读取子账户的空凭据。

管理员权限统一读取 `auth.loginUser.isAdmin`。管理员接口中的“不能删除自己”等保护必须比较 `auth.loginUser.id`，不能比较当前子账户 ID。

`/users/me` 在子账户下返回子账户名称和 `email: null`，`isAdmin` 字段使用登录主账户的真实权限。

## 验收标准

- 子账户不能登录。
- 现有登录会话升级后继续使用主账户。
- 主账户只能切换自己的子账户。
- 切换后 `/users/me` 返回子账户名称，邮箱为空。
- 管理员主账户在子账户中仍保留管理员权限。
- 切回主账户后恢复主账户数据和权限。

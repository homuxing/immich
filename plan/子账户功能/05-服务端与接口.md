## 接口

### 查询子账户

```http
GET /users/me/subaccounts
```

```json
[
  {
    "id": "uuid",
    "name": "插画",
    "createdAt": "2026-10-28T10:00:00.000Z"
  }
]
```

只返回当前登录主账户自己的子账户。

### 创建子账户

```http
POST /users/me/subaccounts
```

```json
{
  "name": "插画"
}
```

服务端校验名称非空且在同一主账户下唯一，然后自动生成用户 ID、存储标签和独立人脸分组。

### 修改名称

```http
PUT /users/me/subaccounts/:id
```

```json
{
  "name": "素材"
}
```

只允许修改名称。

### 删除子账户

```http
DELETE /users/me/subaccounts/:id
```

返回 `204 No Content`。删除会处理会话、数据库记录和物理文件。

### 切换子账户

```http
POST /auth/active-account
```

```json
{
  "subaccountId": "uuid"
}
```

只允许登录会话调用。服务端校验子账户属于当前主账户后更新 `session.activeUserId`。

### 返回主账户

```http
DELETE /auth/active-account
```

把 `session.activeUserId` 设为 `null`。

### 查询当前账户

`GET /auth/status` 增加：

```json
{
  "loginUserId": "uuid",
  "activeUserId": "uuid-or-null",
  "isSubaccount": true
}
```

## 服务端行为

### 子账户创建

- `name` 去除前后空格后必须非空。
- 查询同一 `parentUserId` 下是否已有同名子账户。
- `email`、`password`、`oauthId` 和 `pinCode` 为空。
- `isAdmin = false`。
- 不设置独立配额。
- 创建独立人脸分组。

### 当前账户

- `auth.user.id` 使用 `activeUserId` 或登录主账户 ID。
- `auth.loginUser` 使用登录主账户。
- `auth.session.loginUserId` 使用登录主账户 ID。

管理员权限检查读取 `auth.loginUser.isAdmin`。管理员接口中的自我操作保护使用 `auth.loginUser.id`。

### 仅主账户可用接口

增加统一的 `PrimaryAccountOnly` 路由标记，在认证守卫中检查 `auth.session.activeUserId === null`。至少覆盖：

- `/users/me` 资料修改、头像、License 和 Onboarding。
- `/sessions` 全部会话管理。
- `/api-keys` 全部接口。
- `/passkeys` 全部管理接口。
- OAuth 绑定和解绑。
- 密码和 PIN 管理。
- 子账户创建、改名和删除。

`/auth/session/unlock` 允许在子账户中使用，但必须读取 `auth.loginUser.id` 的 PIN。

### 用户查询

- 用户搜索只返回主账户。
- 管理员默认用户列表只返回主账户。
- 用户总数不统计子账户。
- 服务器统计将子账户文件计入主账户，不把子账户显示为独立用户。
- 用户资料、头像、相册用户、Partner 和人物共享接口拒绝子账户目标。
- 人脸分组用户列表不返回子账户，子账户不能加入其他人脸分组。
- `UserAdminService` 的修改、删除和恢复拒绝子账户目标。

### 会话解析

- 同时读取登录主账户和活动子账户。
- 任一账户已删除、停用或归属不一致时，请求失败。
- 活动子账户被软删除后，相关 `activeUserId` 立即改为 `null`。
- 切换账户后，按登录会话 ID 断开旧实时连接。

### 配额

- 上传时检查主账户配额。
- 子账户记录自己的用量。
- 主账户记录包含全部子账户的总用量。
- 文件新增和删除在同一个数据库事务中更新两份用量。
- 后台任务定期重新计算总用量，修正异常中断造成的偏差。

### 创建限制

- 每个主账户创建子账户时检查服务器配置的数量上限。
- 创建接口执行频率限制。
- 已软删除的子账户不占用名称，但记录在后台清理完成前仍保留。

### 用户数据返回

- `AuthUser.email` 和用户响应中的邮箱允许为 `null`。
- 子账户的 `/users/me` 返回名称、`email: null` 和登录主账户的管理员状态。
- 子账户的配额字段返回登录主账户的配额和聚合用量。
- License 等账号级信息读取登录主账户。
- 修改邮箱头像颜色计算，避免对空邮箱计算头像颜色。

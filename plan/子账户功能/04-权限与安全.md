# 权限与安全

> 所属功能：子账户

## 必须满足的规则

- 子账户不能登录。
- 子账户只能由所属主账户切换使用。
- 主账户未切换时不能读取子账户内容。
- 子账户之间不能互相读取内容。
- 其他用户不能搜索或共享子账户。
- 子账户不能管理账号、共享、配额或管理员权限。
- 系统管理权限只取登录主账户的权限。

## 权限来源

每个请求有两类信息：

- 当前数据账户：决定照片、文件夹、相册、收藏、地图、探索等数据范围。
- 登录主账户：决定系统管理员权限。

当前数据账户是子账户时，`auth.user.id` 使用子账户 ID，`auth.loginUser.id` 使用登录主账户 ID。

子账户数据库记录永远保持 `isAdmin = false`。管理员权限只读取 `auth.loginUser.isAdmin`。

## 服务端检查

### 登录

- 密码登录只允许主账户。
- 子账户不能绑定 OAuth。
- 子账户不能创建 Passkey 或 API Key。
- 登录会话只能记录主账户。

### 子账户管理

- 列表、创建、改名和删除只允许登录主账户执行。
- 修改和删除前必须确认 `parentUserId` 等于当前登录主账户 ID。
- 子账户名称必须在同一主账户下唯一。
- 子账户不能管理自己或其他子账户。

### 仅主账户可用的接口

以下接口必须在服务端统一拒绝子账户：

- 修改邮箱、密码和账号资料。
- 上传或删除头像。
- 创建、修改或删除设备会话。
- 创建或管理 API Key。
- 创建或管理 Passkey。
- 绑定或解绑 OAuth。
- 设置、修改或重置 PIN。
- 修改 License 和 Onboarding。
- 创建、改名或删除子账户。

使用统一的主账户接口标记和守卫实现，不能逐页面前端隐藏。

### 数据

- 照片、文件、相册、人物、标签、回忆、收藏、地图、探索和搜索使用 `auth.user.id`。
- 通过猜测用户 ID、照片 ID、相册 ID 或旧页面地址不能跨账户访问。
- 子账户不进入主账户的 Partner 时间线。

### 共享

子账户严格禁止：

- 邀请或被邀请加入相册。
- 建立 Partner。
- 共享人物。
- 请求加入其他人脸分组。
- 创建分享链接。

共享、Partner、人物共享和人脸分组接口必须同时拒绝当前账户是子账户以及目标是子账户的请求。

### 账号安全

子账户上下文禁止：

- 修改密码或 PIN。
- 绑定或解绑 OAuth。
- 创建或删除 Passkey。
- 创建或删除 API Key。
- 修改账号邮箱。

### 管理员

- 管理员入口和接口检查 `auth.loginUser.isAdmin`。
- 子账户不会增加管理员权限。
- 子账户不出现在管理员默认用户列表。
- 服务器用户数量不统计子账户。
- 管理员接口不能直接修改或删除子账户，必须走子账户专用接口。
- 管理员操作中的自我删除、角色修改等检查使用 `auth.loginUser.id`。

### 引用目标

以下接口接收用户 ID 时，必须拒绝子账户：

- 查询用户资料和头像。
- 相册添加用户。
- Partner 创建。
- 人物共享。
- 管理员用户查询、修改、删除和恢复。

只过滤用户搜索列表不够，直接提交子账户 ID 也必须被拒绝。

## 客户端安全

切换数据账户后必须清理：

- 普通查询缓存。
- 照片时间线缓存。
- 文件夹树。
- 照片多选状态。
- 当前打开的旧照片页面。
- 旧实时连接。

服务端在切换后使旧实时连接失效。客户端重新连接并加载当前账户数据。

实时连接建立时会加入当前账户 ID 对应的房间。账户切换后，服务端必须按登录会话 ID 主动断开旧连接；只依赖客户端重连会继续收到旧账户事件。

## 存储配额

- 子账户不能设置独立配额。
- 子账户文件计入主账户总用量。
- 子账户不能通过创建更多数据空间绕过主账户配额。

## 必测安全场景

- 子账户不能登录。
- 同一主账户下不能创建重名子账户。
- 不同主账户可以使用相同子账户名称。
- 子账户不能创建账号凭据或分享链接。
- 主账户未切换时不能读取子账户照片。
- 子账户 A 不能读取子账户 B 的照片。
- 管理员主账户在子账户中仍可进入系统管理。
- 非管理员主账户在子账户中不能进入系统管理。
- 删除子账户后旧会话不能继续访问。

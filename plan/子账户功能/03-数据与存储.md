# 数据与存储

> 所属功能：子账户

## 数据库修改

```sql
ALTER TABLE "user"
ADD COLUMN "parentUserId" uuid NULL
REFERENCES "user" ("id") ON DELETE RESTRICT;

ALTER TABLE "user"
ALTER COLUMN "email" DROP NOT NULL;

ALTER TABLE "user"
ADD CONSTRAINT "user_primary_email_required"
CHECK ("parentUserId" IS NOT NULL OR "email" IS NOT NULL);

ALTER TABLE "user"
ADD CONSTRAINT "user_subaccount_name_required"
CHECK ("parentUserId" IS NULL OR btrim("name") <> '');

CREATE UNIQUE INDEX "user_parent_name_unique"
ON "user" ("parentUserId", lower(btrim("name")))
WHERE "parentUserId" IS NOT NULL AND "deletedAt" IS NULL;

CREATE INDEX "user_parentUserId_idx"
ON "user" ("parentUserId")
WHERE "parentUserId" IS NOT NULL;

ALTER TABLE "session"
ADD COLUMN "activeUserId" uuid NULL
REFERENCES "user" ("id") ON DELETE SET NULL;

CREATE INDEX "session_activeUserId_idx"
ON "session" ("activeUserId")
WHERE "activeUserId" IS NOT NULL;
```

现有用户保持 `parentUserId = null`，现有会话保持 `activeUserId = null`。

`parentUserId` 必须使用 `ON DELETE RESTRICT`。删除主账户前先逐个删除子账户，避免数据库先删除记录而留下物理文件。

增加数据库触发器，确认父账户自身的 `parentUserId` 为空，防止多层嵌套。

## 创建子账户

服务端自动生成：

- 用户 ID。
- 唯一存储标签。
- 独立人脸分组。

用户只填写名称。服务端固定设置为：

```text
parentUserId       当前主账户 ID
email              null
password           null
oauthId            null
pinCode            null
isAdmin            false
quotaSizeInBytes   null
```

存储标签格式：

```text
<主账户标签或主账户 ID>-sub-<子账户短 ID>
```

## 数据隔离

切换后，当前数据账户 ID 是子账户 ID。以下内容继续按用户 ID 查询：

- 照片和时间线。
- 文件夹。
- 相册。
- 收藏、归档和回收站。
- 地图和探索。
- 搜索。
- 人物和标签。
- 回忆。
- 用户偏好。

普通用户搜索、共享对象选择和管理员默认用户列表只查询：

```sql
WHERE "parentUserId" IS NULL
```

服务器用户数量也只统计主账户。

## 物理存储

每个子账户使用独立目录：

```text
upload/<子账户 ID>/
thumbs/<子账户 ID>/
encoded-video/<子账户 ID>/
profile/<子账户 ID>/
library/<子账户 storageLabel>/
```

文件夹视图从当前账户照片的原始路径生成，因此不会混入主账户目录。

## 配额

- 子账户没有独立配额。
- 主账户配额限制主账户和全部子账户的总用量。
- 每个子账户继续记录自己的用量。
- 主账户展示的总用量包含全部子账户。
- 上传前使用登录主账户的配额和聚合用量，不能使用子账户的空配额判断。
- 上传和文件删除时，在同一个数据库事务中更新子账户用量和主账户总用量。
- 后台用量同步任务重新计算主账户及其全部子账户的总用量。

## 删除

删除子账户必须：

1. 先把指向该子账户的 `session.activeUserId` 改为 `null`。
2. 软删除并阻止继续访问。
3. 删除相册成员关系和其他关联数据。
4. 通过现有用户删除任务删除数据库记录。
5. 删除 upload、thumbs、encoded-video、profile 和 library 目录。
6. 从主账户总用量中扣除该子账户用量。

删除主账户时：

1. 先把主账户标记为不可登录。
2. 逐个完成全部子账户的文件和数据库清理。
3. 子账户全部删除后，才允许删除主账户记录。

## 旧数据

- 不搬迁现有照片和目录。
- 现有用户全部视为主账户。
- 现有邮箱继续保留。
- 迁移只增加字段、索引和约束。

# 子账户功能总览

> 基线版本：Immich `3.3.0-rc.0`  
> 更新时间：2026-10-28  
> 状态：最终方案

## 目标

主账户用子账户存放插画、表情包等不需要进入主时间线的内容。子账户不是独立账号，而是同一主账户下的数据空间。

每个子账户拥有独立的时间线、文件夹、相册、收藏、地图、探索、搜索、人物、标签、回忆、回收站和物理存储目录。

## 最终方案

- 子账户是 `user` 表中的隐藏数据记录，通过 `parentUserId` 关联主账户。
- 子账户只有一个非空名称，在同一主账户下不能重名。
- 子账户没有邮箱和密码，不能登录。
- 主账户通过已有登录会话在子账户之间切换。
- 子账户不拥有独立配额，所有文件计入主账户存储配额。
- 子账户没有独立账号管理、共享、Partner、API Key、Passkey 或 OAuth。
- 系统管理员权限以登录的主账户为准。子账户本身不拥有管理员权限。
- Web 端和移动端同时支持创建、改名、删除和切换子账户。

## 变更范围

### 数据库

- `user` 增加 `parentUserId`。
- `user.email` 允许为空，主账户仍必须填写邮箱。
- 子账户名称在同一主账户下唯一。
- `session` 增加 `activeUserId`。

### 服务端

- 增加子账户查询、创建、改名、删除和切换接口。
- 子账户不计入服务器普通用户数量。
- 子账户不出现在用户搜索和管理员默认用户列表中。
- 子账户不能登录、共享或创建独立访问凭据。
- 子账户不能创建设备会话、API Key、Passkey、OAuth 或账号资料。
- 用户资料、头像、相册、Partner 和管理员接口拒绝子账户目标。
- 子账户文件计入主账户配额，用量更新和文件删除保持事务一致。
- 管理员接口只使用登录主账户的管理员权限和自我操作保护。
- 删除主账户前必须完成全部子账户文件和记录清理。

### Web 与移动端

- 用户设置中增加子账户管理。
- 账户菜单中增加子账户切换。
- 切换后清理旧账户的查询缓存、照片时间线、文件夹树、多选状态和实时连接。
- 子账户模式隐藏账号安全、共享和子账户管理入口。
- 管理员入口按主账户权限显示。
- 服务端在切换后主动断开旧实时连接。

### 接口与客户端代码

- 新增服务端接口和接口数据结构。
- 重新生成 Web 和移动端接口代码。

## 破坏性修改

- 数据库必须执行字段和索引迁移。
- `email` 从必填改为可空，现有主账户仍必须保留邮箱。
- 子账户名称只允许非空值，并按主账户范围去重。
- 子账户上下文会拒绝账号资料、设备会话、凭据和子账户管理接口。
- 登录会话会根据 `activeUserId` 选择当前数据空间。
- 删除主账户必须先清理子账户，不能依赖数据库级联。
- 现有主账户不会改变数据归属，但所有客户端必须重新生成接口代码。
- 一旦创建子账户，直接降级到旧版 Immich 可能无法正确管理隐藏记录和文件。降级前必须恢复旧版备份。

## 与旧版本兼容性

- 现有主账户、邮箱、密码、照片和相册不受影响。
- 现有登录会话升级后 `activeUserId` 为空，继续使用主账户。
- 现有主账户不参与新的子账户名称唯一性检查。
- 现有主账户资料、设备会话、API Key、Passkey、OAuth 和分享功能不变。
- 旧版客户端不能管理或切换子账户，但主账户原有功能继续可用。
- 子账户管理、切换和展示要求服务端、Web 和移动端一起升级。
- 升级前必须备份数据库和媒体目录；降级必须恢复对应备份。

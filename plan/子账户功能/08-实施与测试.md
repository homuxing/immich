# 实施与测试

> 所属功能：子账户

## 实施顺序

1. 修改 `user` 和 `session` 表，增加字段、索引和名称唯一约束。
2. 修改登录会话，按 `activeUserId` 返回当前数据账户。
3. 在请求中同时保存登录主账户和当前数据账户，管理员权限只读取登录主账户。
4. 增加子账户查询、创建、改名、删除和切换接口。
5. 修改用户搜索、用户数量、共享和 Partner 限制。
6. 增加仅主账户可用接口守卫，禁止子账户创建凭据和设备会话。
7. 修改配额统计，使子账户文件计入主账户并保持事务一致。
8. 重新生成 OpenAPI、Web 接口代码和移动端接口代码。
9. 完成 Web 管理页、切换器和缓存清理。
10. 完成移动端管理、切换、本地数据和上传任务处理。
11. 完成删除流程和全量测试。

## 数据库测试

- 新字段、索引、邮箱可空和名称唯一约束可以正常迁移。
- 现有用户迁移后仍是主账户。
- 现有登录会话迁移后仍使用主账户。
- 同一主账户不能创建重名子账户。
- 不同主账户可以使用相同子账户名称。
- 子账户名称不能为空白。
- 软删除子账户后可以重新使用相同名称。
- 主账户仍必须有邮箱。

## 登录与权限测试

- 主账户可以正常登录。
- 子账户不能登录。
- 子账户不能创建 OAuth、Passkey 或 API Key。
- 子账户不能创建设备会话。
- 子账户不能修改账号资料、头像、License 或 Onboarding。
- 主账户只能切换自己的子账户。
- 管理员主账户切换后仍保留管理员权限。
- 非管理员主账户切换后仍没有管理员权限。
- 子账户不能管理账号或共享。

## 数据测试

- 主账户与子账户照片互相不可见。
- 子账户 A 与子账户 B 照片互相不可见。
- 时间线、文件夹、相册、收藏、地图、探索、搜索、人物、标签、回忆和回收站全部隔离。
- 通过照片 ID、相册 ID 和旧页面地址不能跨账户访问。
- 子账户不能参与共享或 Partner。
- 用户资料、头像和共享接口直接提交子账户 ID 时被拒绝。
- 子账户不能加入其他人脸分组，分组用户列表不返回子账户。

## 配额测试

- 子账户上传计入主账户总用量。
- 子账户删除文件后主账户总用量正确减少。
- 主账户配额达到上限后，所有子账户都不能继续上传。
- 创建多个子账户不能绕过主账户配额。
- 并发上传、删除和后台同步后，主账户总用量保持一致。
- 超过服务器配置的子账户数量上限后不能继续创建。

## 客户端测试

- Web 切换后旧查询、文件夹树、多选状态和实时连接全部清理。
- 服务端在切换后断开旧账户实时连接。
- 同一浏览器多个标签页在切换后全部更新到正确账户。
- 移动端切换后旧时间线、相册、上传和同步任务全部停止或重新加载。
- 刷新页面或重启 App 后恢复正确账户。
- 管理员入口按主账户权限显示。

## 删除测试

- 子账户数据库记录被删除。
- upload、thumbs、encoded-video、profile 和 library 目录被删除。
- 删除后旧登录会话无法访问子账户。
- 删除主账户时所有子账户目录被清理。
- 主账户记录不能在子账户清理完成前被删除。

## 发布检查

- 升级前备份数据库和媒体目录。
- 在测试实例执行数据库迁移。
- 验证主账户原有登录、上传、相册、文件夹、人物、标签、分享和后台任务。
- 验证 Web 和移动端使用同一服务端版本。
- 降级时恢复旧版数据库和媒体备份。
